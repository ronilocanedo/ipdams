## Cause and fix

The site-wide CSS applies `nav { flex-direction: column }`. v0.2.311's scoped reimbursement tab CSS included `display:flex` but did not override flex-direction. The tabs therefore appeared in a centered vertical stack. The higher-specificity `nav.travel-311-tabs[role="tablist"]` v0.2.312 rule explicitly sets `flex-direction:row`, `flex-wrap:nowrap`, horizontal overflow and compact per-tab buttons; sidebar navigation is unaffected.
