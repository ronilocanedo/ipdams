## Implementation

- Keep semi-expendable report's existing identity, **REPORT OF SEMI-EXPENDABLE PROPERTY ISSUED**, rather than incorrectly relabeling it as supplies and materials.
- Render the read-only report using a **CSP-safe new external CSS file** `public/assets/semi-issued-report.css`, A4 portrait, Appendix 64-inspired bordered tables, aligned supply/accounting column groups, recapitulation, total and separate certification / posting signature boxes.
- `app/Domain.php` extends the existing authenticated school-scoped `property.registration.detail` response with the **true catalog item ID**, and `division.item_uacs` response with account titles resolved from `uacs_accounts` for **existing scoped mappings**, including inactive historical titles. All additions are **read-only**.
- `public/assets/app.js` uses the existing authenticated Division mapping API only when preparing the semi-expendable report. For each exact catalog item it selects a **single Division-approved UACS mapping effective on the recorded ICS issuance date**. An unmapped, ambiguous, invalid or later mapping is **never invented**; code and title remain blank. The code and exact account title are passed to the printer and HTML-escaped.
- `public/assets/ics-ris-pair-print.js` adds the standalone formal semi-report rendering and external CSS reference. **No change** to the separate Print ICS, Print RIS or Print RIS + ICS paths. A finalized ICS remains the source; printing doesn't create documents or accounting postings. Do not substitute its ICS number as a true RIS number. The report serial, fund source, posting identity or actual RIS number stay blank when no authentic saved source exists.
- `public/app.html`: new JS cache references to activate the printer after refreshing.
- No database migration, stock/custody write, property change, print-time numbering or financial approval.
