## Change

Allow **Allowed**, **Partially Allowed**, and **Excluded** documentary expense review decisions with an empty Reason field. An employee's original claimed amount is never reduced or rewritten; preliminary allowable amounts still reconcile with the selected decision. The authenticated reviewer is still recorded in the review version/audit event, and older reasons remain intact. Optional reviewer, paper reference, and explanation fields stay optional.

**Narrow documentary exception:** positive allowance of a fare that overlaps a **documented actual** seminar session still needs the explicit `AUTHORIZED_MOVEMENT` finding and either an existing Actual Itinerary supporting reference or a review evidence reference. User can instead Exclude or mark Needs Evidence without providing an allowance justification.
