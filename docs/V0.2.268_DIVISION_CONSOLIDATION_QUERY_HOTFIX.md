# IPDAMS v0.2.268 — Division Consolidation SQL hotfix

## Incident
Owner installed v0.2.267 on Nov 2, 2026. Division Consolidation Overview returned “Database operation failed” (screen reference b34ec899). Source review found that v0.2.267 introduced `a.organization_id=m.organization_id` in **two** SQL statements against `asset_movements m` (Overview ASSET_EVENT count and ASSET_EVENT register). The underlying asset-movement record uses `asset_id` and does not store an independent organization_id. This was not detected by the v0.2.267 mock tests.

## Narrow correction
Restore the owning-organization join through `assets a ON a.id=m.asset_id` in both paths; retain `WHERE a.organization_id IN (?,…)` with per-user authorized office IDs. All other v0.2.267 Division Office + authorized-school scoping, current/accepted transferred property rules, condition columns, document history, permissions and view logic remain unchanged.
