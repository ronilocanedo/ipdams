## Scope

- Existing authenticated **Print RIS + ICS** action now builds formal **Appendix 63 RIS** and **Appendix 59 ICS** as separate A4 sheets, with grouped columns, clean borders, blank reserve rows, purpose, printed names/designations and signature boxes as in user-supplied examples.
- **Print ICS** always uses Appendix 59 for single-unit and multi-unit ICS, not the older generic one-asset format.
- **Inventory Management → issued supplies RIS → Print RIS** now renders Appendix 63, not JSON; only existing authenticated `ISSUED` RIS may print. Verify document registry number and original saved `document_versions` RIS-line membership/quantities against current linked line entries before printing. Reverse/nonissued or inconsistent documents are rejected.
- CSS is an external same-origin stylesheet and never depends on inline styles within the browser's about:blank popup; the popup has a separate print-click binding. Required browser print controls stay outside the paper.
- Fund cluster, division RCC, wet signatures, dates and other missing documentary fields remain blank. The **companion property RIS does not acquire a made-up RIS registry number** from the ICS; a blank is left when no independent RIS number is recorded. ICS retains its real identity. No invented approvals or signatures.
- `PAR`, textbook RIS/ITR, procurement, reports, ICS/PAR issuance, custody, assets, inventory, SQL or financial accounting unaffected.
- Preserves `renderSemiIssued` Appendix 64 browser report code unchanged.
