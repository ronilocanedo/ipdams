## Changes

- **Super Admin Office Viewer**: available office selector for all server-returned Divisions and schools, with default-on read-only user-interface mode on Super Admin login/refresh, explicit on/off control and contextual banner. Main React API writes are blocked during viewing; standalone Property transfer/return/incoming/lifecycle forms are hidden in viewer mode. Authenticated sign-out still works. This is **not a new server role or a cryptographic/server-side read-only security boundary**; the already privileged Super Admin can consciously leave view mode. Schools retain existing server-enforced organization scopes, no cross-school access grants or impersonation.
- **Property and Inventory UI**: preserve existing routes and tab keys, use compact horizontally scrollable tabs, dark high-contrast table headings, column dividers, alternating rows and mobile scrolling. Historical property registration, ordinary Inventory RIS creation, RIS issue and opening-balance actions now use floating dialogs; Property Details and audit screens remain as before.
- **Original fund / source of historical acquisition**: optional 160-character evidence field `original_fund_source` under `assets.property_profile.shared` for `HISTORICAL_OPENING` only. Examples include DepEd MOOE, SEF, LGU, PTA, donations or grants. Separate from `acquisition_type`. Displays on Property Details → Acquisition and audited shared-value changes. Ordinary `VERIFIED_IAR` cannot accept a nonempty value. Changes after finalized ICS/PAR remain locked under current provenance rules. No financial source ID, fund balance, property cost or stock posting is affected.
