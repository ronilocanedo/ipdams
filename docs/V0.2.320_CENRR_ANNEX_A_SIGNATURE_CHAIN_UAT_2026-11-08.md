## Changes

CENRR now prints as **ANNEX A**, matching the owner's supplied fully bordered DepEd format: employee/office/division, individually selected dates, expense descriptions/amounts, total, purpose, certification text, and Certified Correct / Noted by signature columns.

**Noted by rule:** if claimant is a **teacher**, use the appointed **School Principal** in the scoped directory; if claimant is **Principal/School Head**, use the **SDS** from the linked Travel Authority snapshot, **not the ASDS** (ASDS is the separate Appendix 45 certifier rule). Certified Correct is always the claimant. Missing/mismatched signatories remain blank and are flagged in-app rather than guessed.

No per diem in Annex A. CENRR selection remains independently confirmed, fare/other only, no-receipt, individual entries ≤ ₱300. Existing backend financial/documentary approval controls remain intact. Print CSS is loaded via a dedicated same-origin stylesheet (CSP-compatible). It halts if CSS unavailable.
