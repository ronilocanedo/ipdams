## Root cause

v0.2.327's `eligibleTravelDvClaims` silently skipped all travel RCs that failed a prereq, and Employee dropdown options were built only from those successful rows. Saved-but-unverified travel claims could therefore disappear completely. The new function lists the newest 100 valid tenant-scoped RCs, attaching strict server-side readiness flags and readable reason messages. UI shows unready rows as nonselectable and only shows the accounting-review action for fully reviewed claims; the draft-create path remains strict and unchanged.

No separate `Finalize Claim` workflow exists: recorded paper-document compliance, independent Division verification, completed chronological expense decisions, then the separately recorded Division/Super Admin accounting review render a claim draft-DV eligible. A review saved on an older claim version is stale after subsequent document verification.
