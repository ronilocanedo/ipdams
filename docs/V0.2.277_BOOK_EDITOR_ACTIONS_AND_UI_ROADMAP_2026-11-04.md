- Draft Add/Edit Book: **Save Draft**, **Verify & Publish**, **Cancel**. Publish still requires an authentic valid ISBN or genuine official LR code and checked verification attestation.

- Existing server-side minimum-eight-character correction reason and append-only before/after audit remain intact; updates continue to use `textbook.catalog.update`.
- Close an unchanged editor without an unnecessary lost-changes prompt; still warn for unsaved changes.
- Saving an edited verified book no longer automatically opens the New Central Office Receipt form, and the success notice explains that an audited correction was saved.
- No stock movement, SQL changes, backend permission modifications, or changes to existing CO receipt safety gates.
