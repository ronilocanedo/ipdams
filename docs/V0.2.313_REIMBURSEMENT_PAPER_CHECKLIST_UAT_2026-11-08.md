## Changes

Reimbursement → Documents replaces new attachment upload controls with checkboxes for the four required paper-document types plus Appendix 45 when applicable. Staff can save incomplete or complete on-file confirmations; every checklist write creates a versioned claim snapshot and separate audit event with actor/time. No scans required. Existing attached scans remain viewable and old scan-based evidence verification stays compatible.

Independent Division/Super Administrator reviewer must complete the existing six-point review, and cannot be the claim preparer. Server verifies all relevant checklist categories before recording `DOCUMENTS_CHECKED_FOR_ACCOUNTING_REVIEW`. The review remains *documentary*, not DTE allowability, financial approval, DV creation, fund allocation, obligation or payment. Edits to a claim invalidate the prior paper checklist, leaving earlier attestation intact in historical versions.

Five application files: `app/TravelReimbursement.php`, `public/api/index.php`, `public/assets/app.js`, `public/assets/travel-313.css`, `public/app.html`. Existing v0.2.312 horizontal subtabs CSS is retained.
