## Root cause
In v0.2.321, the **Appendix 47 Print Certificate** handler invoked:
`if(cenrrNotedBy.warning) ...`
but `cenrrNotedBy` exists only in the separate **Annex A CENRR** print handler. This raised `ReferenceError: cenrrNotedBy is not defined`, displayed as `Print halted: cenrrNotedBy is not defined`.

The fix removes only the misplaced CENRR block from Appendix 47. The legitimate CENRR Noted-by check (Teacher→Principal, Principal→SDS) is preserved. An updated JS URL in app.html forces the browser to load corrected code.
