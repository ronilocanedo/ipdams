**Root cause:** v0.2.313 functional React state update dereferenced `e.target.checked` after React synthetic event recycling, producing `TypeError: Cannot read properties of null (reading 'checked')` and a white screen. The separate CENRR expense-selection checkbox had the same bug. Both now synchronously capture `e.currentTarget.checked` before entering the deferred updater. Asset cache version is bumped.

**Reproduction:** delayed-state-update simulation fails on v0.2.313, passes on corrected v0.2.314. Five document compliance checkbox clicks and one CENRR checkbox pass. Legacy on-file checklist render/save payload regression, JS syntax, manifest SHA256, ZIP CRC and predecessor gate pass. Authenticated Hostinger/browser database test pending.

**Scope:** UI event handlers and JS cache bust only. No changes to claims, audit records, expenses, signatories, DV, funds, payments, attachments, server review validation, or migrations. Unsubmitted checkbox clicks after a crash may be lost; saved claim history is unaffected.

GitHub is a **documentation-only checkpoint**, not a deployable complete source mirror. Only the independently verified Drive ZIP should be installed using IPDAMS System Updates after backup.
