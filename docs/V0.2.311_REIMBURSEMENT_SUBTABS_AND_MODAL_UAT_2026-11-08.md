## Purpose

Reimbursement page was excessively long with all claim registers, each itinerary expense, supporting documents, CENRR, checklists and reports expanded at once. Version 0.2.311 introduces five independently displayed subtabs: Claims (compact register/search), Actual Itinerary (read-only Appendix 45 summary/print), Documents (uploads and CENRR), Expense Review (authorized reviewer checklist and chronological timeline), Reports (separate without-receipts report with CSV/print/pagination).

Preparing or revising an Actual Itinerary opens a wide floating editor. Each expense line opens a second compact universal Transportation/DTE/Others entry window with editable From/To locations, Time From/To and inline receipt/support fields. New lines inherit the prior explicit destination and end time; prior route wording remains unchanged if not edited. Cancel restores draft fields, and saving the claim continues through existing versioned, authenticated API workflows.
