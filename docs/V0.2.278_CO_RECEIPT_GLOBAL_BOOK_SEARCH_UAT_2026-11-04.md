## User requirement implemented

On **Textbooks → CO Receipts → + New CO receipt**, replace the plain ISBN input with an accessible rich-result global book search. Search by **title, ISBN-10/13, author, grade/level, subject, publisher or edition**. A match shows title, ISBN-13, grade, author, edition, subject, publisher (where recorded). Select an edition to fill the exact canonical ISBN used in the original receipt backend. Prevent duplicate ISBNs on different lines. Include eligible verified profiles and valid historical ISBN registry entries; exclude drafts, invalid ISBN and contradictory duplicates. No new stock movements, fabricated titles, or access to other offices' private draft data.
