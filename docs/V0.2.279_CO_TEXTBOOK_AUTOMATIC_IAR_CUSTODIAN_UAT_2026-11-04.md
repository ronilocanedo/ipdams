## Background

The existing CO textbook receipt uses a separate `TBR` document and did not automatically issue a print-ready IAR. The `TextbookCoReceiptWorkflow::inspect` function refused entries from the appointed Property Custodian's linked login because `PROPERTY_RECEIVING_LOGIN_V1.user_id` matched the currently authenticated inspector. Its `accept` method likewise blocked the same login even if the independent inspectorate signatory had signed paper evidence. The user wants one appointed property custodian to record the documented physical quantities and later accept the actual CO delivery.

**DepEd documentary separation remains mandatory:** the Inspectorate Team's genuine signed inspection and the custodian's subsequent signed acceptance are distinct roles. Entering findings using one login is not permission for one person to sign both functions. Relevant policy evidence: DepEd DO 5 s.2010 and published DepEd delivery inspection protocols.

## Implementation

1. Automatically reserve an **official continuous annual `IAR` number** at the creation of a CO receipt draft, inside the existing transaction. Persist it in the original `TBR` document snapshot and immutable versions. Use the same annual counter as ordinary IARs so CO receipt numbering does not collide with other IAR issuances. No local PO, invoice or procurement `iars` row is fabricated.
2. Add `TextbookCoIar.php`: independent, scoped, escaped Appendix 62-style printable IAR derived exclusively from the audited receipt. The document shows book descriptions, ISBNs, delivery/inspection quantities, signed inspectorate evidence, correct actual inspection date, separately marked receiving custodian and acceptance, and prominent draft warnings where relevant. It is **not** an electronic signature.
3. Expose authenticated read-only `textbook.co_receipt.iar.print` and audited idempotent `textbook.co_receipt.iar.issue` for pre-upgrade receipts. The latter adds the IAR number to a new historical version without stock posting, and may be used on earlier completed receipts without inventing the original inspection date.
4. Replace the same-user blanket denial: a linked custodian may **record** inspection findings using their own login only with the actual **different** inspection officer's name/designation, genuine signed inspection reference, confirmation, actual inspection date, and observed quantities. Do not allow the custodian's own official name as independent inspector. Preserve old genuinely separate authenticated inspections. Still require the effective-dated linked custodian login and separately signed acceptance evidence before stock is credited.
5. Enforce actual inspection date `>=` physical delivery and acceptance date `>=` inspection/delivery, quantity reconciliation, office scopes, original immutable histories and at-most-once stock postings.
6. Add **Linked IAR** column and **View / Print IAR** to Textbooks → CO Receipts. Earlier TBRs get a **Generate linked IAR** action. No changes to Property and Inventory modules.
