## User-facing workflow

- **Disbursements → + Prepare DV → Employee Travel.**
- Each fully reviewed, document-verified travel claim is shown with amount claimed, preliminary allowed, separately accounting-confirmed amount, employee/fund, and reservation state. Division or authorized Super Administrator records an explicitly attested accounting review.
- Select multiple eligible claims for ONE employee, ONE organization and ONE funding source, and **Save Draft Travel DV**. Server derives the gross/net and payee from locked source records, retains claim and review versions, and inserts immutable claim link and allocation lines.
- Existing `REIMBURSEMENT` DV is still for *procurement advances*, distinct from travel.
- Duplicate active claims, mixed employee/funds, stale review/claim versions, unreviewed lines, prior advances/payment-authorized flags, or unsupported amounts fail closed.
- Cancelling an unnumbered DRAFT releases its active reservations without deleting earlier audit/link rows.
- **Travel DV FINALIZATION, account posting, DV numbering and physical check issuance are explicitly BLOCKED in both the server and frontend until authenticated accounting and MariaDB UAT.** This is not full payment integration.
