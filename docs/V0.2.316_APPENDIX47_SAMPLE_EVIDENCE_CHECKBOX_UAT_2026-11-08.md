## Behavior

Print the **Certificate of Travel Completed (Appendix 47)** using the owner's supplied sample as layout reference: upper-right Appendix label, centered title, entity/fund cluster, upper school/division station details, slash-mark travel-condition choices, explanation and evidence sections, and right-side employee/SDS handwritten-signature blocks. An unobtrusive footer makes the unsigned-draft status explicit.

The certificate editor contains five evidence checkboxes — Certification of Travel Completed (Appendix 47), Itinerary of Travel, Annex A, Used Tickets, and Certificate of Appearance — with an optional additional-evidence text area. Only selected standard evidence titles plus additional text print in the evidence section, one line per entry. Checked values persist in the existing versioned `completion_certificate.evidence_of_travel` string, and old free-text evidence is retained.

The code captures checkbox values synchronously before React state updates (avoids prior event-release white screens). Printing HTML escapes user-entered data. Saves retain the v0.2.315 paper-checklist reconfirmation and independent Division review rules. No uploads, monetary postings or electronic approval.
