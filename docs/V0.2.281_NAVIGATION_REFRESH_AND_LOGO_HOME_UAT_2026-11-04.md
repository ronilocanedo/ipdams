## Scope

1. Clicking IPDAMS main sidebar navigation updates non-sensitive URL parameter `section`. When supported, clicking the module subtab updates `pane`. Refreshing the application restores both, after authenticated session and workspace scope validation.
2. **Tapping the IPDAMS logo returns to Dashboard**: clickable sidebar brand, mobile IPDAMS brand, and upper header/banner logo. It clears the selected page/subtab so refreshing afterward stays on Dashboard. Accessible buttons support pointer and keyboard.
3. Preserves actual user/office scopes from `auth.session`, applies role restrictions, and falls back to Dashboard for unknown or unauthorized restored navigation. No unsaved form inputs, financial data, record identities, credentials or tokens enter the URL. No server role or permission grants changed.
4. Does not change CO textbook receiving, automatically printed IARs, document acceptance, physical stock movements or Book Directory updates.
