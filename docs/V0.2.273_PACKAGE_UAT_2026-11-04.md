## Implemented in installable ZIP
- Add Book saves draft with title + material type only. Optional full bibliographic information: ISBN, official LR code, grade/subject, author, publisher, edition, publication year, language, curriculum, references, notes, etc.
- The **receiving school** (origin) and its **supervising Division Office** edit school-added entries; Division-added entries are edited by originating Division only. Technical SUPER_ADMIN, other schools and unrelated Divisions have no operational edit override.
- Global ISBN-10/ISBN-13 normalization and authentic LR-code duplication gates. No fake ISBNs. Verified ISBN editions reuse `textbook_titles`; official LR-only material is not receipt-ready until that receiving path is implemented.
- Shared verified catalog, private un-identified drafts, minimally discoverable identified drafts pending verification (to prevent silent duplicate ISBN).
- Append-only book profile versions in existing `document_registry` / `document_versions` / `audit_events` (TBP). No new SQL tables or schema migrations. Verified identity locked and corrections require reason and history.
- No physical stock posting upon book registration/edit. Existing TBR inspection and custodian acceptance workflow kept byte-for-byte unchanged.
- Selective textbook reset blocked when it would orphan versioned book profiles.
